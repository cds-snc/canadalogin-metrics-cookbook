Jira (PSOM)

Metrics in this section are calculated from PSOM Jira Service Management ticket data.

The relevant Jira tables are:

  • jira.psom - daily snapshot of all PSOM tickets
  • jira.psom_sla - the SLA clocks on each ticket, one row per ticket per SLA
  • jira.psom_comment - every comment on each ticket

Data cadence. The tables are updated once per day (at ~06:00 ET); before 2026-09-29 they were updated weekly, on Mondays. Each run writes a full snapshot of all tickets currently in the project to a new date= partition; previous partitions are preserved as an audit trail. Always filter to date = (SELECT MAX(date) FROM <table>) when querying the latest state. Join the tables on key and date.

PSOM Metrics

Metric Description
Tickets by Status PSOM tickets in the latest snapshot, by workflow status.
Weekly Ticket Volume Number of PSOM tickets in each Monday snapshot.
Tickets by Priority PSOM tickets in the latest snapshot, by priority.
SLA First-Response Breach Rate Share of PSOM tickets that missed the time-to-first-response SLA.
SLA Time-to-Done Breach Rate Share of PSOM tickets that missed the time-to-done SLA.
